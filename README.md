# NIHS_SD-ASM

Analysis code for: *Genome-wide profiling of sequence-dependent allele-specific
methylation identifies a candidate regulator of lipid traits* — a study of
sequence-dependent allele-specific methylation (SD-ASM) in the Norfolk Island
Health Study (NIHS) founder population, integrating whole-genome bisulfite
sequencing (WGBS), whole-genome sequencing (WGS), RNA-seq, and phenotype data.
